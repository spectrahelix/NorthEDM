# Book-derived calculators

Empty until the owner supplies material from their book (title, author, edition).

For each method added here record:

- **Name** of the calculation and the book's chapter/page it comes from.
- **Definition** in our own words: inputs, letter/number table, steps, edge cases.
- **Worked examples** from the book, used as test fixtures before the method ships.
- **Tradition label** and how it differs from standard gematria — never switch a
  report's method silently; each method is a separately labeled setting.
